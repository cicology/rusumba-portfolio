The project

Alpha Insure prices motor insurance through Akur8, a third-party actuarial rating engine. Before any pricing change reaches a real customer quote, it has to be validated against hundreds of scenarios, and doing that by hand, one case at a time, was slow, error-prone, and didn''t scale with how often the rating logic changed.

This tool exists to make that validation fast, repeatable, and auditable.

What I did

  • Built the full stack solo, React/Vite frontend, Node/Express backend, and Firebase/Firestore for storage and history, end to end.
  • Bulk test execution, upload CSV-defined test batches that run sequentially against the Akur8 rating API, with live pass/fail/error tracking as the run progresses.
  • Input validation up front, invalid rows are flagged before a run starts, so a malformed test case never silently burns a batch.
  • Auditable history, every run is stored and searchable in Firestore, and results export cleanly for re-import and comparison.

Where it landed

The tool is in active use for pre-deploy validation of Alpha Insure''s motor pricing. What used to be a manual, one-at-a-time check is now a bulk run with a clear pass/fail signal and a full audit trail, the kind of safety net that lets a pricing team ship changes with confidence.
